# RainbowBridge

Static site for [RainbowBridge](https://rainbowbridgellc.org), a consultancy that staffs AI and ML model-training specialists for evaluation, fine-tuning, and domain task design. The page is a single document: practice, method, partner network, experts, and a briefing form that opens a `mailto:` to `support@rainbowbridge.org`.

## File layout

```
index.html      Page markup
styles.css      Layout and visual styles
main.js         Mobile nav, footer year, and briefing form
favicon.svg     Site icon
assets/logos/   Partner marks used in the network section
CNAME           GitHub Pages custom domain
```

## Preview locally

Open `index.html` in a browser, or from this directory:

```bash
npx serve .
```

## Deploy

The site is published with GitHub Pages. The custom domain is the hostname in `CNAME` (`rainbowbridgellc.org`).
